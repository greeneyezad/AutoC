# Changelog

All notable changes to AutoC will be documented in this file.

- Added a more robust type inference path for `auto` assignments and binary expressions.

- Added a project-level test suite covering parser, runtime execution, ownership checks, and IR output.
- Added GitHub project metadata for public collaboration and automated validation.

## 0.1.0

- Initial public prototype with lexer, parser, AST, Python code generation, and a minimal language spec.
